# KREYOH Profile Signal Note

This pass deliberately keeps artist profiling UI-only and does not add a new schema.

The current contributor, role, beat interest, beat assignment, and activity records are the right foundation for a future recommendation layer. When profiling expands, add structured attributes for genre, language, mood/energy, vocal or creative style, influences, and collaboration history without replacing the existing role and event records.

No external AI service or recommendation engine is part of the current shell lock.
